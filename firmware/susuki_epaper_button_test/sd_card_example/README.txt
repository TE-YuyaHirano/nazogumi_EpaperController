Copy the contents of this folder to the root of the microSD card.

Required image paths:
  /assets/me_close.jpg
  /assets/me_open.jpg

Image format:
  JPEG, 480 x 800 pixels

Settings file:
  /setting.txt

The included test images are red versions of the built-in black artwork.
If red artwork appears on the e-paper, the image was loaded from microSD.
